# ESP32-C3 · DHT22 Monitor

Веб-монитор температуры и влажности на **ESP32-C3** и датчике **DHT22**: график с историей, личный кабинет, управление GPIO-устройствами, уведомления в Telegram и на e-mail, HTTP API для внешних систем и настройка через Serial.

## Возможности

- Показания DHT22 (температура, влажность) на главной странице и график с настраиваемой историей.
- Личный кабинет с паролем: управление устройствами на GPIO и все настройки.
- Уведомления в Telegram и по e-mail при выходе температуры или влажности за границы.
- HTTP API (температура, влажность, аптайм) — включается и защищается паролем в кабинете.
- Статический IP или DHCP, доступ по имени `http://<имя>.local` (mDNS).
- Контроль заряда батареи через делитель на АЦП.
- Автоматическое переподключение к WiFi, в том числе полный сброс WiFi-стека при долгой потере связи.
- Время по NTP, индикация состояния светодиодами.
- Настройка WiFi и пароля администратора через USB-кабель без перепрошивки.

## Железо и подключение

| Назначение | GPIO | Примечание |
|---|---|---|
| DHT22 (data) | 5 | |
| Светодиод WiFi | 12 | горит при подключении к сети |
| Светодиод TX | 13 | коротко вспыхивает при HTTP-запросе |
| Батарея (АЦП) | 2 | через резисторный делитель |

Пины 5, 12, 13 и 2 зарезервированы — их нельзя назначить устройствам в кабинете. Остальные GPIO (0–21) можно использовать для управляемых устройств.

Делитель батареи по умолчанию: R1 = 230 кОм (верхний), R2 = 1033 кОм (нижний). Значения, границы заряда (4.2 В / 3.0 В) и калибровочный коэффициент меняются в кабинете.

## Установка

1. Установите в Arduino IDE поддержку плат ESP32 (**Arduino core 3.x**).
2. Через Library Manager установите:
   - `ESPAsyncWebServer` (me-no-dev)
   - `AsyncTCP` (me-no-dev)

   Остальное (`Preferences`, `WiFiClientSecure`, `HTTPClient`, `ESPmDNS`) входит в ESP32 core. DHT22 читается напрямую, библиотека DHT не используется.
3. Создайте рядом со скетчем файл `secrets.h` с данными WiFi для первого запуска:

   ```cpp
   #pragma once
   #define WIFI_SSID     "MyHomeWiFi"
   #define WIFI_PASSWORD "my-wifi-password"
   ```

   Эти значения используются, пока WiFi не настроен через кабинет или Serial; после этого действуют сохранённые в NVS.
4. Выберите плату ESP32-C3, при необходимости поправьте часовой пояс (`GMT_OFFSET_SEC`, по умолчанию UTC+3) и загрузите скетч.

## Первый запуск

1. Откройте Serial Monitor (115200 бод) — там будет виден IP-адрес устройства.
2. Откройте `http://<IP>` или `http://webserver.local`.
3. Войдите в **Кабинет** с паролем по умолчанию **`admin123`** и сразу смените его (вкладка «Настройки» → «Безопасность»).

## Веб-интерфейс

### Главная страница

Температура и влажность, график, уровень заряда батареи, свободная память, часы, аптайм и статус связи (Online/Offline). Данные обновляются автоматически; если датчик не отвечал дольше минуты, показания не выводятся.

### Личный кабинет

Вход по паролю администратора, одна активная сессия (повторный вход или выход сбрасывает предыдущую).

**Вкладка «Устройства»** — до 16 устройств на GPIO: название, пин, состояние Вкл/Выкл. Состояние сохраняется и восстанавливается после перезагрузки.

**Вкладка «Настройки»:**

| Раздел | Что настраивается |
|---|---|
| Основные | подпись на главной странице, размер шрифта интерфейса, коррекция температуры (°C) |
| График | число точек (10–1000) и период между ними (10 с – 24 ч) |
| Wi-Fi сеть | SSID, пароль, DHCP или статический IP (маска, шлюз, DNS), сетевое имя mDNS |
| Параметры батареи | границы заряда, резисторы делителя, калибровочный коэффициент |
| Индикация | включение светодиодов WiFi и TX |
| Безопасность | пароль администратора |
| API | включение API и пароль API |
| Уведомления | границы, Telegram, e-mail (см. [Уведомления](#уведомления)) |

Каждая точка графика — среднее по всем замерам датчика за период. При смене периода накопленная история очищается, при смене числа точек — нет. История хранится в ОЗУ и сбрасывается при перезагрузке.

Раздел «Wi-Fi сеть» сохраняется отдельной кнопкой и сразу переподключает устройство. Если ввести неверные данные, устройство станет недоступно — тогда сеть исправляется через [Serial](#настройка-через-serial).

## HTTP API

Простой API для скриптов и систем умного дома. **По умолчанию выключен.** Включается в кабинете: «Настройки» → «API». Там же можно задать пароль (необязательно).

### Эндпоинты

| Метод и путь | Ответ |
|---|---|
| `GET /api/sensor` | JSON с названием устройства, температурой, влажностью и аптаймом |
| `GET /api/sensor/temperature` | температура, `text/plain` |
| `GET /api/sensor/humidity` | влажность, `text/plain` |
| `GET /api/sensor/uptime` | аптайм в секундах, `text/plain` |

Пример ответа `/api/sensor`:

```json
{"label":"ESP32-C3 Monitor","temperature":23.4,"humidity":45.1,"uptime":86400}
```

- `label` — название устройства: подпись, заданная в настройках («Подпись слева сверху на главной странице»).
- `temperature` — °C, `humidity` — %, `uptime` — секунды с момента включения.
- Если датчик не отвечал дольше минуты, `temperature` и `humidity` равны `null`; на отдельных эндпоинтах в этом случае возвращается `503 unavailable`.

### Пароль

Если пароль задан, передайте его одним из способов:

```bash
# заголовок X-API-Key
curl -H "X-API-Key: mypassword" http://webserver.local/api/sensor

# заголовок Authorization: Bearer
curl -H "Authorization: Bearer mypassword" http://webserver.local/api/sensor

# параметр в URL (удобно для браузера, но пароль попадает в логи и историю)
curl "http://webserver.local/api/sensor/temperature?key=mypassword"
```

Пароль API: 4–32 печатных ASCII-символа без пробелов. Он не связан с паролем администратора и никогда не возвращается устройством — в кабинете отображается только факт, что он задан. Пустое поле при сохранении оставляет текущий пароль; чтобы убрать пароль, отметьте «Удалить пароль».

### Коды ответов

| Код | Значение |
|---|---|
| `200` | успех |
| `401` | пароль не передан или неверный |
| `403` | API выключен в настройках |
| `404` | неизвестный путь |
| `503` | нет актуальных данных датчика или устройство занято |

> Страница мониторинга использует собственный служебный эндпоинт `/api/data`. Он не документирован, может меняться и не защищён паролем API — для интеграций используйте `/api/sensor`.

## Уведомления

Контроль выполняется после каждого успешного чтения датчика. Сообщение отправляется при выходе значения за границы и при возврате в норму; пока значение вне нормы, оно повторяется с заданным интервалом (0 — не повторять, максимум 1440 мин).

- Для температуры и влажности границы и включение задаются отдельно.
- Чтобы шум датчика у границы не порождал поток сообщений, возврат в норму фиксируется с гистерезисом: 0.5 °C для температуры и 2 % для влажности.
- **Telegram:** токен бота и `chat_id`.
- **E-mail (SMTP):** сервер, порт (465 — SSL/TLS, остальные — STARTTLS, обычно 587), логин, пароль (для Gmail и подобных — пароль приложения), один или несколько получателей через запятую.
- Секреты (токен бота, пароль SMTP) не отдаются обратно в интерфейс; пустое поле при сохранении оставляет сохранённое значение.
- Кнопки «Отправить тест» проверяют каждый канал отдельно; ошибки отправки показываются в интерфейсе.

> Сертификаты серверов Telegram и SMTP **не проверяются** (в прошивке нет хранилища корневых сертификатов). Трафик шифруется, но подмена сервера в локальной сети теоретически возможна.

## Настройка через Serial

Можно перенастроить WiFi или сменить пароль администратора через USB-кабель, без перезагрузки устройства.

### Подключение

1. Подключите ESP32-C3 к компьютеру USB-кабелем.
2. Откройте монитор последовательного порта (Serial Monitor в Arduino IDE, Web Serial, PuTTY, Tera Term и т. п.).
3. Параметры:
   - **Baud Rate:** `115200`
   - **Line Ending:** `LF` (или `CR + LF`)

### Команды

Введите команду и нажмите `Enter`.

#### `help` — справка

Выводит список доступных команд.

#### `status` — состояние системы

Показывает:

- имя текущей WiFi-сети (SSID), IP-адрес и статус подключения;
- число переподключений и хард-реинитов WiFi;
- число таймаутов мьютекса;
- время без связи (если сеть недоступна);
- состояние API: включён или выключен, задан ли пароль;
- текущие температуру и влажность;
- напряжение батареи (или сообщение, что сигнала нет).

#### `wifi` — смена WiFi-сети

1. Отправьте `wifi`.
2. На запрос `[WiFi] Введите SSID сети:` введите имя сети.
3. На запрос `[WiFi] Введите пароль сети:` введите пароль.
4. Параметры сохраняются в NVS, устройство отключается от старой сети и сразу подключается к новой. **Перезагрузка не требуется.**

> Если в кабинете включён статический IP, он продолжит применяться и в новой сети. Если новая сеть в другой подсети, сначала верните DHCP в кабинете либо убедитесь, что адрес подходит.

#### `password` — смена пароля администратора

1. Отправьте `password`.
2. На запрос `[Admin] Введите новый пароль администратора (от 4 до 32 символов):` введите пароль.
3. Пароль сохраняется, выводится `[Admin] Пароль администратора успешно изменен!`. Если длина не подходит, запрос повторится.

Пароль API этой командой не меняется — он настраивается в кабинете.

### Примечания

- Если ввод для `wifi` или `password` начат, но не завершён, через **60 секунд неактивности** устройство возвращается в обычный режим.
- Все параметры сохраняются в NVS (Preferences) и действуют после выключения питания.
- При вводе WiFi-пароля в монитор выводится его эхо открытым текстом — учитывайте это, если рядом посторонние.

## Как работает устройство

- **Опрос датчика:** раз в 50 с; если период точек графика короче 100 с — чаще (не меньше двух замеров за окно). При сбое делается до 3 попыток; ошибка попадает в очередь сообщений интерфейса.
- **Переподключение WiFi:** первые 6 попыток с интервалом 10 с, затем раз в 60 с. Если связи нет дольше 5 минут, выполняется полный сброс WiFi-стека (не чаще раза в 2 минуты).
- **Время:** NTP (`pool.ntp.org`, `time.nist.gov`), часовой пояс задаётся константой `GMT_OFFSET_SEC`. История графика начинается после первой синхронизации времени.
- **Хранение:** настройки, устройства и параметры уведомлений лежат в NVS (пространства `settings`, `devices`, `notify`). История графика — только в ОЗУ.
- **Уведомления** отправляются из основного цикла (TLS-рукопожатие блокирующее, занимает 1–3 с).

## Безопасность

- Веб-интерфейс и API работают по обычному **HTTP** без шифрования — используйте их только в доверенной сети и не открывайте устройство в интернет напрямую.
- Смените пароль администратора по умолчанию `admin123`.
- Включайте API только если он нужен, и задайте для него пароль; не используйте тот же пароль, что и для кабинета или других сервисов.
- Пароли и токены хранятся в NVS в открытом виде.
